# Дорожная карта

Готово: чаты и звонки, каналы как в Telegram, «Кометы», лента, видео, компании в стиле Discord, сообщества, статистика, режим «Пространство», номер телефона и поиск по нему, почта с кодами.

## Следующий этап

- [ ] **Админка аккаунта** — панель владельца: пользователи, жалобы, блокировки, статистика сервиса, рассылки
- [ ] **Звонки с «фишкой»** — новый вид экрана звонка и функция, ради которой зовут друзей: групповые комнаты, совместный просмотр, эффекты
- [ ] Групповые звонки и демонстрация экрана
- [ ] Прямые эфиры в каналах

## Мелочи, которые делают удобно

- [ ] Стикеры, GIF-поиск, свои эмодзи
- [ ] Предпросмотр ссылок (безопасный, через серверный прокси)
- [ ] Прыжок к закреплённому сообщению в переписке
- [ ] Аватары групп, каналов, компаний и сообществ из интерфейса
- [ ] Треды (серии постов), ответы-ветки в группах
- [ ] Перетаскивание чатов между категориями в компаниях

## Безопасность и приватность

- [ ] Double Ratchet (forward secrecy) для секретных чатов, мультиустройства
- [ ] Шифрование вложений в секретных чатах, E2E для групп (MLS)
- [ ] Ключи доступа (passkeys / WebAuthn)
- [ ] Подтверждение номера телефона по SMS
- [ ] Проверка паролей по утечкам (HIBP, k-anonymity)
- [ ] Антиспам и автомодерация

## Платформа

- [ ] Web Push-уведомления
- [ ] Транскодирование видео (HLS, несколько качеств)
- [ ] PostgreSQL, Redis для реалтайма, S3 для медиа (см. [архитектуру](ARCHITECTURE.md#как-масштабировать-дальше))
- [ ] Английский и другие языки
- [ ] Нативные приложения (React Native / Capacitor) на том же API
- [ ] Bot API и мини-приложения
