# Дорожная карта

Фундамент готов: архитектура, безопасность, навигация и все базовые сценарии. Дальше — «дом из маленьких функций». Пункты, отмеченные 🧭, уже есть в навигации как разделы «скоро».

- [ ] Стикеры, GIF-поиск, свои эмодзи 🧭
- [x] Черновики и отложенные посты; треды (серии постов) — впереди
- [x] Свои папки чатов с правилами
- [x] Упоминания @ в группах; ответы-ветки в группах — впереди
- [ ] Предпросмотр ссылок (безопасный, через серверный прокси)
- [ ] Прыжок к закреплённому/найденному сообщению в переписке
- [ ] Редактирование аватаров групп, каналов и сообществ из интерфейса
- [x] Архив и «Актуальное» историй, «Близкие друзья», реакции, текстовые истории
- [x] Списки авторов в ленте, коллекции закладок, скрытые слова

## Связь

- [x] Аудио- и видеозвонки 1:1 на WebRTC (DTLS-SRTP)
- [ ] Групповые конференции, демонстрация экрана 🧭
- [ ] Прямые эфиры 🧭

## Безопасность и приватность

- [ ] Double Ratchet (forward secrecy) для секретных чатов, мультиустройства
- [ ] Шифрование вложений в секретных чатах
- [ ] E2E для групп (MLS)
- [ ] Ключи доступа (passkeys / WebAuthn) как альтернатива паролю
- [ ] Проверка паролей по утечкам (HIBP, k-anonymity)
- [ ] Серверное удаление EXIF и пережатие медиа (сейчас — на клиенте)
- [ ] Антиспам и автомодерация, расширенная панель модератора

## Платформа

- [ ] Web Push-уведомления
- [ ] Транскодирование видео (HLS, несколько качеств), превью при наведении
- [ ] PostgreSQL, Redis для реалтайма, S3 для медиа (см. [архитектуру](ARCHITECTURE.md#как-масштабировать-дальше))
- [ ] Локализация (английский и другие языки)
- [ ] Нативные приложения (React Native / Capacitor) на том же API
- [ ] Bot API и мини-приложения 🧭

## Сервисы 🧭

Музыка, подкасты, маркетплейс, кошелёк, игры, афиша, облако, бизнес-профили, ассистент — места в навигации уже готовы, каждый подключается как отдельный модуль в `apps/server/src/modules` и `apps/web/src/features`.
