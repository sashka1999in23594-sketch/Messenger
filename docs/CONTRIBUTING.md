# Как развивать SpaceUp

## Добавить раздел в навигацию

1. Откройте `apps/web/src/app/navigation.ts` и добавьте узел в нужное место дерева:
   ```ts
   { id: 'home.mine.drafts', label: 'Черновики', icon: PenLine, path: '/feed/drafts' }
   ```
2. Добавьте маршрут в `apps/web/src/app/routes.tsx` — он автоматически заработает и в обычном режиме, и в окнах «Пространства».
3. `npm test` проверит, что в навигации нет тупиков (каждый пункт ведёт на маршрут).

Раздел сразу появится в дереве, хлебных крошках, мобильной шторке и палитре Ctrl+K.

## Добавить функцию на сервере

1. **Контракт.** Опишите входные данные zod-схемой в `packages/shared/src/schemas.ts`, а ответ — типом в `types.ts`.
2. **Миграция.** Если нужны новые таблицы/колонки — добавьте **новую** миграцию в конец `apps/server/src/db/migrations.ts` (опубликованные не меняются).
3. **Сервис.** Бизнес-логика — в `apps/server/src/modules/<модуль>/<модуль>.service.ts`. Решения о доступе — через `Policy`, не дублируйте их.
4. **Маршруты.** В `<модуль>.routes.ts`: `requireAuth(req)`, `parse(schema, req.body)`, вызов сервиса. Для чувствительных действий — свой `rateLimit`.
5. **Регистрация.** Создайте сервис в `context.ts`, подключите маршруты в `app.ts`.
6. **Тест.** Добавьте сценарий в `apps/server/test/` — особенно для всего, что касается доступа и приватности.

## Добавить экран в клиенте

- Код раздела — в `apps/web/src/features/<раздел>/`, экспорт страниц из `index.tsx`.
- Данные — через `api` и TanStack Query (`useCursorList` для бесконечных списков, ключи — в `shared/api/query.ts`).
- Компоненты — из `shared/ui` (кнопки, поля, модальные окна, меню, пустые состояния, аватары, медиа).
- Цвета и отступы — только CSS-переменные из `styles/tokens.css`, чтобы работали тёмная тема, акценты и масштаб текста.
- Проверьте экран на ширине 390 px (телефон) и 1440 px.

## Правила

- Текст пользователя — только через `<RichText>` (без HTML).
- Никаких секретов в коде и логах; новые настройки окружения — в `config.ts` и `.env.example`.
- Перед коммитом: `npm run typecheck && npm test`.
