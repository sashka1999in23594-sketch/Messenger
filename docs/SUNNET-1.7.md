# Sunnet 1.7 — что нового и как настроить

Основа — версия 1.6.0. Всё ниже работает на сервере Render и в приложении для компьютера 1.7.0.

## Вход и сеансы
- Сеанс подписан APP_SECRET и восстанавливается, если база откатилась после засыпания Render. Смена пароля и блокировка обнуляют старые сеансы.
- Экран пробуждения сервера с этапами и таймером; через 2,5 мин — «Сервер не отвечает» с повтором.
- **Важно:** без S3 (Backblaze B2) на бесплатном Render при засыпании стираются и аккаунты, и файлы. Заполните S3_* в Render.

## Обновление приложения для компьютера
Проверка при запуске и каждые 5 минут, журнал — `updater.log` в папке данных приложения. Новая версия выходит, когда в `main` меняется `desktop-app/` (поднимите `version` в `desktop-app/package.json`).

## Рабочий стол = облако
Папки, файлы, ярлыки, проекты Студии хранятся на сервере (`/desk/items`). Корзина, восстановление, копия облака в файл. Панель задач, размер значков и сортировка синхронизируются между устройствами.

## Студия, Академия, приложения
- Студия: `/studio/<проект>`; скрипты на SunScript (JavaScript + `screen`, `ui`, `sunnet`), проверка ошибок без запуска кода.
- Приложения запускаются в песочнице (CSP `sandbox allow-scripts`, без cookie и сети).
- Публикация → ссылка `/app/<имя>`; проверка по согласию автора: `/app.pending()`, `/app.verify("имя")`, `/app.reject("имя")` в консоли.
- Разрешения (уведомления, файлы, камера, микрофон, экран) — каждое отдельно, история и отзыв: Настройки → Безопасность → Разрешения приложений.

## Telegram и WhatsApp в общем списке чатов
| Переменная | Где взять |
| --- | --- |
| TELEGRAM_API_ID, TELEGRAM_API_HASH | my.telegram.org → API development tools |
| WHATSAPP_VERIFY_TOKEN | придумайте и укажите в Meta for Developers → WhatsApp → Configuration → Webhook |
| WHATSAPP_APP_SECRET | Meta for Developers → App settings → Basic → App secret |

Вебхук WhatsApp: `https://<ваш-сервис>/api/v1/bridge/whatsapp/webhook`, подписка на `messages`. Личные аккаунты WhatsApp официального доступа не дают — только Business.

## Серверы и Sunnet Connect
Мастер в разделе «Серверы»; Sunnet Connect — `connect-app/` (инструкции в `connect-app/README.md`).

## Администрирование
`ADMIN_USERNAMES=ваш_ник` в Render → после перезапуска у вас роль admin и консоль (Настройки → Консоль администратора). Все команды пишутся в журнал аудита.
