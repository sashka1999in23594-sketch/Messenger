# Sunnet 1.8 — что нового

## Интерфейс
- Кнопки-капсулы и мягкие карточки выбора вместо серых прямоугольников (`apps/web/src/styles/polish.css`).
- Солнце в центре дока — «Найти всё» (Ctrl K): разделы и функции, свои чаты, люди, каналы, номера
  телефонов, облако, серверы, приложения. Строка поиска сверху и лупа в доке убраны.
- Звонок: снова есть «Сцена» (карандаш), добавлены «Картинка в картинке» и «Снимок звонка в облако».
- Reels, видео, истории: «+» сразу открывает выбор файла, детали заполняются после.

## Облако = рабочий стол
- В облако можно положить файл любого типа. Неизвестные типы хранятся как двоичные и отдаются только
  на скачивание (`Content-Disposition: attachment`, `nosniff`, CSP `sandbox`) — открыть их внутри Sunnet нельзя.
- Любая загрузка показывает анимацию: файлик летит по дуге в облако, сверху процент (`shared/ui/UploadFx.tsx`).
- Файлы можно бросать и поверх окон: если окно само их не приняло, они уходят в облако.
- Браузер и Корзина — системные значки на рабочем столе, удалить их нельзя.

## Браузер
- Поиск по всему интернету: сервер разбирает выдачу Bing (RSS), запасной вариант — DuckDuckGo, плюс Википедия
  (`apps/server/src/modules/browser/websearch.ts`). Пользователю уходит только список ссылок.
- В приложении для компьютера сайты открываются во встроенном браузере Sunnet (`desktop-app/src/inapp.js`):
  - работают все сайты, вход, видео;
  - сайт в песочнице, без доступа к Node и к сессии Sunnet;
  - у каждого стороннего приложения (Telegram, WhatsApp, Instagram, Twitch…) свой изолированный профиль;
  - скачанное загружается в облако и удаляется с диска.
- Непрочитанные из открытых приложений (число из заголовка страницы) видны вверху общего списка чатов.
- Веб-версия: браузеры не позволяют показывать чужие сайты внутри страницы (заголовки `X-Frame-Options`/CSP
  самих сайтов), поэтому сайты открываются в новой вкладке. Полная интеграция — в приложении для компьютера.

## Администрирование
- Первый зарегистрированный настоящий пользователь становится администратором, если других администраторов
  нет (демо-аккаунты `@example.com` не считаются). `ADMIN_USERNAMES` по-прежнему работает.
- 65 команд в 15 разделах: `/help.all()`, `/help.find("блок")`. Личные переписки и тайный вход в чужой
  аккаунт недоступны и администрации; каждая команда пишется в журнал.

## Приложение для компьютера
- «Чёрный экран»:
  - сервер больше не отдаёт `index.html` вместо пропавших файлов сборки;
  - service worker не кэширует страницы ошибок;
  - сторож запуска (`public/boot-guard.js`) и само приложение чистят устаревший кэш и перезагружают страницу,
    если интерфейс не появился.
