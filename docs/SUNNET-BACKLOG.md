# Sunnet — пожелания владельца (вести и не терять)

## Интерфейс
- Светлая солнечная тема по умолчанию, анимации везде (с настройкой «Уменьшить движение»).
- Левая панель окна — разделы + бесконечная лента возможностей (сделано: FeatureFeed).
- **Аватар:** возможность загрузить/сменить аватар; если не загружен — красивый аватар из первых букв имени (градиент, стильно).
- **Пустые состояния без огромных кнопок:** экран «Выберите, кому написать» с крупными кнопками «Новый чат / Новая группа» заменить на стильное решение (компактные действия, иллюстрация, подсказки, горячие клавиши).
- Фото интерфейса — на согласование перед большими изменениями.

## Критичное (после одобрения фото)
- Авторизация и вход на рабочий стол, автовыход при простое, сохранение сеанса.
- Автообновление приложения для компьютера (electron-updater) с экраном прогресса и откатом.
- Экран пробуждения сервера Render с повтором и понятной ошибкой.

## Экосистема
- Облако = рабочий стол: синхронизация через сервер (сейчас — локально на устройстве).
- Орбита (+): каталог → расширить до 1000+ через серверный каталог.
- Единый центр чатов (Telegram API и др.), подписки, Студия и публикация, серверы и Sunnet Connect,
  браузер, безопасность и изоляция, админ-консоль `/user.block("ник", duration: 7d)`.
